# 📱 HackerLocker — إصدار أندرويد (جولات الأندرويد)

**الملف:** `locker_android.py` — **الإطار:** Kivy — **كلمة المرور الافتراضية:** `782106202`
**النسخة:** v1.0 — تعمل على: Android (عبر Termux) أو أي حاسوب مثبّت عليه Kivy

> ⚠️ للاختبار المصرّح به فقط — أجهزتك أو أجهزة مختبر الاختراق.

---

## 1) لماذا Kivy؟
- `tkinter` غير موجودة على أندرويد أصلاً.
- **Kivy** هي مكتبة الواجهات الأساسية على أندرويد وتدعم ملء الشاشة بدون إطار، وحقول كلمة المرور، ولوحة المفاتيح الافتراضية تظهر تلقائياً، وتعمل أيضاً على الحاسوب لتجربة سريعة.

---

## 2) التثبيت والتشغيل على أندرويد (Termux)

```bash
pkg update && pkg upgrade -y
pkg install python python-pip libsdl2 libsdl2-dev clang make -y
pip install kivy

# من داخل مجلد الملف:
python locker_android.py
```

عرض توضيحي آمن للبداية: غيّر `DEFAULT_PASSWORD` داخل الملف مؤقتاً ثم أعد استخدامه، أو جرّب على الحاسوب أولاً (أدناه) — **النسخة لا تحتوي وضع ديمو تلقائي** لأن أندرويد يغلق التطبيق بسهولة (زر Home/رجوع).

---

## 3) التشغيل على الحاسوب (للتجربة السريعة / تطوير الجولة)

```bash
python -m pip install kivy
python locker_android.py
```

---

## 4) آلية العمل على أندرويد

1. `Window.fullscreen = "auto"` → نافذة بملء الشاشة بلا أزرار إغلاق.
2. عرض شعار ASCII الهكر + الرسالة (عربي/إنجليزي).
3. حقل كلمة المرور (مخفية بـ `password=True`).
4. التحقق عبر SHA-256 من كلمة المرور `782106202`.
5. **5 محاولات خاطئة → تجميد الإدخال 15 ثانية** (مكافحة التخمين).
6. الإدخال الصحيح → إغلاق التطبيق وعودة الجهاز للطبيعي.

---

## 5) حدود صادقة جداً على أندرويد

| الحد | التفصيل |
|---|---|
| قفل مستوى التطبيق فقط | لا يوجد أي تطبيق (حتى بكامل الصلاحيات عادةً) يستطيع قفل نواة أندرويد من وضع userland |
| هروب سهل للضحية | زر **Home / رجوع** أو قائمة التطبيقات الأخيرة يغلق التطبيق |
| التشكيل العربي | خط Kivy الافتراضي قد لا يظهر العربية متصلة على كل الأجهزة؛ يمكن تثبيت خط عربي (مثل Amiri/Noto) ووضع مساره في `FONT_PATH` أعلى الملف |
| بلا تشفير | لا يشفر ولا يحذف أي ملف — محاكاة واجهة فقط |

**الاسترجاع عند نسيان كلمة المرور:** Home/رجوع → إغلاق التطبيق، أو `pkill -f locker_android` من Termux.

## 6) بناء تطبيق APK حقيقي

صارت ملفات البناء كاملة داخل **مجلد `apk_build/`** بجوار هذا الملف:

| الملف | الوظيفة |
|---|---|
| `apk_build/main.py` | نسخة التطبيق (نسخة مطابقة من `locker_android.py`) |
| `apk_build/logo.png` | الشعار — أيقونة التطبيق وشاشة البدء |
| `apk_build/buildozer.spec` | إعدادات Buildozer (Kivy 2.3.1، معمارية aarch64، ملء شاشة) |
| `apk_build/.github/workflows/build-apk.yml` | بناء سحابي تلقائي عبر GitHub Actions |
| `apk_build/README_BUILD.md` | دليل البناء بالتفصيل (سحابي/محلي/Docker) |

**الأسهل:** ارفع مجلد `apk_build/` إلى GitHub → تبويب **Actions** → **Run workflow** → نزّل الـ APK من Artifacts بعد ~30-45 دقيقة.

> دمج `locker_android.py` مع نسخة سطح المكتب لهذه الجولة يجعل السيناريو موحداً (نفس كلمة المرور `782106202`).
